# Elasticsearch Tokenizer и Filters

## Tokenizer: Типы и их различия

### Основные типы `Tokenizer`
- **`standard`**:  
  Разделяет текст на слова, учитывая пробелы и пунктуацию.  
  **Пример:** `"The quick-brown fox"` → `["The", "quick", "brown", "fox"]`

- **`whitespace`**:  
  Разделяет текст только по пробелам.  
  **Пример:** `"The quick-brown fox"` → `["The", "quick-brown", "fox"]`

- **`keyword`**:  
  Сохраняет весь текст как один токен.  
  **Пример:** `"The quick-brown fox"` → `["The quick-brown fox"]`

- **`pattern`**:  
  Использует регулярное выражение для разделения текста.  
  **Пример:** Регулярное выражение: `"-"`  
  Текст: `"quick-brown-fox"` → `["quick", "brown", "fox"]`

- **`ngram`**:  
  Создает n-граммы заданной длины.  
  **Пример:** `"fox"` с `min_gram: 2, max_gram: 3` → `["fo", "ox", "fox"]`

- **`edge_ngram`**:  
  Генерирует n-граммы только с начала слов.  
  **Пример:** `"fox"` с `min_gram: 2, max_gram: 3` → `["fo", "fox"]`

- **`uax_url_email`**:  
  Распознает URL и email-адреса.  
  **Пример:** `"john.doe@example.com"` → `["john.doe@example.com"]`

- **`char_group`**:  
  Разделяет текст на основе групп символов.  
  **Пример:** Группы: `[",", ".", "-"]`  
  Текст: `"quick,brown.fox"` → `["quick", "brown", "fox"]`

## Filters: Типы и их функции

### Основные фильтры:
- **`lowercase`**:  
  Приводит текст к нижнему регистру.  
  **Пример:** `"Hello"` → `"hello"`

- **`stop`**:  
  Удаляет стоп-слова (например, "and", "or").  
  **Пример:** `"the quick brown fox"` → `["quick", "brown", "fox"]`

- **`asciifolding`**:  
  Преобразует символы с акцентами в базовую форму.  
  **Пример:** `"résumé"` → `"resume"`

- **`length`**:  
  Фильтрует токены по длине.  
  **Пример:** `"a quick fox"` с `min: 2` → `["quick", "fox"]`

- **`snowball`**:  
  Стемминг для разных языков, включая английский.  
  **Пример:** `"running"` → `"run"`

- **`synonym`**:  
  Заменяет токены синонимами из словаря.  
  **Пример:** Словарь: `"fast, quick"`  
  Текст: `"fast fox"` → `["quick", "fox"]`

---

### Фильтры для анализа текста:
- **`porter_stem`**:  
  Стемминг на основе алгоритма Портера.  
  **Пример:** `"running"` → `"run"`

- **`shingle`**:  
  Создает последовательности токенов (шинглы).  
  **Пример:** `"quick brown fox"` → `["quick", "quick brown", "brown", "brown fox", "fox"]`

- **`unique`**:  
  Удаляет дублирующиеся токены.  
  **Пример:** `["quick", "quick", "fox"]` → `["quick", "fox"]`

---

### Специальные фильтры:
- **`truncate`**:  
  Обрезает токены до указанной длины.  
  **Пример:** `"quick"` с `length: 3` → `"qui"`

- **`reverse`**:  
  Переворачивает токены.  
  **Пример:** `"fox"` → `"xof"`
